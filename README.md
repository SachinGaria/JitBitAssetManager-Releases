# JitBit Asset Manager Releases

Official Windows x64 distribution repository for **JitBit Asset Manager**.

This public repository contains release binaries, checksums, and release notes only. The application source remains in the private development repository.

## Installation

Download the latest **JitBitAssetManager-win-x64.zip** from the Releases page, extract it to a folder, and run:

`JitBitAssetManager.exe`

## Updating

Updater-enabled builds use **Profile → Check for Updates** to check this repository for a newer release.

The application downloads the package and verifies its SHA-256 checksum before applying an update.

## Release contents

Each release contains the Windows x64 application package and a `checksums.txt` file.

## Security

Do not publish credentials, access tokens, employee information, asset records, or internal configuration in this repository.
